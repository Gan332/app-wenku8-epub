旅途的开始

风从麦田上吹过来，带着干燥的香气。少女把斗篷的兜帽往后推了推，露出耳朵尖上细细的绒毛。

“前面就是下一个镇子了。”她说，声音很轻，却盖过了车轮碾过碎石的声音。

商人没有立刻回答。他只是在心里算着日子，算着这一路的花销，也算着身边这位旅伴究竟还要同行多久。

路边的界碑被晒得发白，字迹已经看不清了。再往前，是一片缓缓起伏的丘陵，偶尔有炊烟从树梢后面升起来。

“镇子不大，但教堂的钟楼很高。”她像是看出了他的心思，“补给应该够，价钱也不会太离谱。”

车轮继续向前。风把麦浪压出一道又一道的痕，远处的云影从山脊上慢慢滑过去。

Features

为「读下去」而做

不是把网页塞进壳里，而是一套完整的本地阅读工作流。

阅读优先

「阅读」是默认首屏，点书即读。书架卡片主体打开阅读器，详情与导出收进「更多」菜单。

双引擎 EPUB 3

经典引擎保留行内强调标签，Potato 引擎按段落纯文本写入；两种产物都是标准 EPUB 3 + NCX。

整书离线缓存

目录与章节落盘，断网也能读。可设为仅 Wi-Fi 下载，缺失章节会明确提示，而不是空白。

书架与探索

更新检查、未读角标、分组排序、标签浏览与同作者作品，都从同一套书目索引出发。

顺手的阅读器

左右翻页与上下滚动、自动翻页、双击缩放、目录跳章、全书搜索、带摘录的书签中心。

MiuiX 主题

深浅色、动态取色、强调色与 MiSans 字体统一注入；正文背景可独立设置，控件跟随应用主题。

阅读统计

只在前台计时，单次最长 30 分钟。阅读时长、连续天数与最近在读，一目了然。

高刷与省电

自适应 / 60 / 90 / 120 Hz 可选；退到后台立即停止渲染，系统省电模式下跳过视口外预取。

Reader

长时间阅读的细节

分页、滚动、手势与设置都围绕同一件事：让注意力留在正文上。

  • 上下滚动没有断带边距只落在首末页，相邻页之间不再空出一条横缝。
  • 视口外提前排版前后各预取两页，只进位图缓存；滚动到时几乎零等待。
  • 自动翻页可随时停下5 / 10 / 15 / 30 秒；打开面板、锁屏或缩放时自动暂停。
  • 顶栏告诉你读到哪书名下显示当前章节，底部给出页码与百分比。

安装步骤

  1. 下载 app-release.apk（或 Release 页里的 APK 资产）。
  2. 在系统设置中允许当前浏览器或文件管理器「安装未知应用」。
  3. 打开 APK 完成安装；若已装旧版，可直接覆盖升级。
  4. 首次启动按需登录 wenku8，只有需要登录的页面才使用你的会话。

Debug 包仅供调试，体积更大、性能更低，日常请用 release 包。
