# 文库 EPUB 工坊 v0.9.2

修复 0.9.1 遗留的点按呼出菜单栏问题，并完成图片显示、导出排版、阅读断点与书架阅读痕迹。

## 修复

### 点正文呼不出菜单栏（0.9.1 遗留）

0.9.1 验证过：返回键能呼出菜单栏 —— 状态和渲染都正常，只有**内容区的点击**
没到检测器。点按检测改挂到 LazyColumn 节点与正文 item（v0.8.x 实证唯一生效的
层级），父层检测保留用于边距/加载/错误区域。翻页与上下滚动两种模式都覆盖。

### 阅读断点从未真正生效

进度其实一直在存，但读取端被破坏：初始列表信号在定位完成前先发射，把恢复的
章节跳回第 0 章、段落覆盖成 0。现在：

- 打开书先一次性定位到「第 x 章 · 第 y 段」，定位完成前不写进度；
- 翻页模式只给当前章携带恢复段落，防止恢复值串到其它章；
- 退出阅读（onStop）兜底保存最后一次位置；
- 追踪闭包改读「当前」章节号，不再被旧值反复重置。

### 图片无法显示

应用内读取端：

- `src` 路径做百分号解码后再查 zip 条目（`%E6%8F%92%E5%9B%BE.jpg` 之类原样查必失败）；
- 按最长边 2048px 降采样，大插图不再 OOM 静默变空白；
- 引入图片三态：加载中显示转圈、**失败显示带标题的占位框**、成功显示原图 ——
  失败不再隐形。

导出端：插图下载失败不再被静默丢弃，任务会给出
「《章名》有 N 张插图未能下载，已不包含在 EPUB 中」的警告。

### 导出 EPUB 在深色模式下黑底黑字

CSS 里写死的 `body{color:#272522}` 已删除 —— 文字颜色交给阅读器 App 控制。

## 改进

- **导出排版**：段落间距 + 首行缩进 + 孤行控制；插图 `height:auto` 不拉伸、
  不溢出；扉页封面 70% 居中、作者行取消首行缩进、内容简介标题居中；
  MiSans → 思源黑体 → Noto CJK 字体回退。
- **书架阅读痕迹**：卡片新增「上次阅读：3 分钟前 · 读到 第 5 章 · 第 12 段」。
  EPUB 阅读现在也会更新上次阅读时间（此前只有在线阅读在记录）。

## 升级说明

- 无数据迁移变更（沿用 `com.example.hyperreader`）。
- release 包经 R8 压缩，签名由 CI Secrets 提供。

## 验证重点

1. 默认沉浸设置下：**点正文（翻页与上下滚动两种模式）→ 菜单栏滑出；再点收起**；
   返回键行为不变（面板优先关闭 → 可见则退出 → 隐藏则先呼出）。
2. 读到中间退出 → 重开回到**原章原段**；翻页模式不跳页、不串章。
3. 用其他阅读器能正常显示图片的 EPUB 导入 → 应用内能看到图；
   人为损坏场景应显示「图片无法显示：…」占位而不是空白。
4. 导出一本源站带插图的书 → 有图；缺图时任务页出现「查看 N 条警告」。
5. 导出的 EPUB 在外部阅读器开深色模式 → 正文不黑底黑字；段落有间距、插图不变形。
6. 书架卡片显示「上次阅读：… · 读到 第 x 章 · 第 y 段」，未读过的书不显示。
