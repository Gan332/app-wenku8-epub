# v0.3.0 发布说明

发布日期：2026-09-25

## 新增

- MiuiX 应用主题设置：跟随系统、浅色、深色、动态模式和强调色。
- wenku8 登录后按书名或作者搜索。
- 书籍详情新增作者、分类、连载状态、更新时间、全文字数、简介、标签和最新章节。
- 原生 EPUB 阅读器，支持目录、章节切换、插图、左右章节翻页和上下滚动。
- 阅读背景：米黄、白纸、护眼、夜间、OLED 和自定义颜色。
- 自定义 TTF/OTF 字体、字号、字重、行距、段距和左右边距。
- 按书籍、章节和段落保存阅读进度。
- 生成 EPUB 后可以从历史任务直接打开阅读器。

## 安全与边界

- 搜索需要用户主动登录 wenku8；不绕过登录、验证码或访问控制。
- 登录 Cookie 使用 Android Keystore 加密保存，不保存密码。
- EPUB 阅读器支持标准无 DRM EPUB，不支持加密 EPUB。
- 仍只允许 wenku8 允许列表和内网地址阻断。

## 已知限制

- wenku8 搜索和文章列表需要有效登录会话。
- 左右翻页当前按章节切换，章节内部支持上下滚动。
- 主题和阅读设置存储在应用本地，不跨设备同步。
- debug APK 仅供测试安装，正式发布应配置自有签名密钥。
