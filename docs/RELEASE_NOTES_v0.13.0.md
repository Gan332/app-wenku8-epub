# 文库 EPUB 工坊 v0.13.0

阅读器换成 **XY reader**（MIT），数据层仍是本工程实现。0.12.0 引入的
LightNovelReader 阅读器已整体移除。

## 换了什么

- **页面位图阅读器**：正文用 `StaticLayout` 预分页，每页画到透明底位图上，
  翻页时背景色直接透出——左右翻页 / 上下滚动两种模式。
- 点击翻页（可关闭）、双击页内放大、捏合缩放。
- 目录抽屉（目录 / 书签双 tab，当前章高亮）+ 书签增删。
- 阅读设置面板：翻页模式、阅读背景、图片缩放、屏幕常亮、字体、字重、字号、
  首行缩进；阅读配置管理页另有行距、四向边距、字间距、章首另起一页。
- 亮度调节、屏幕方向锁定、手势锁（防误触）、复制当前页文字。
- 内置字体：霞鹜文楷 Lite、MiSans、朱雀仿宋，支持导入自定义字体（ttf / otf / ttc）。

## 保留了什么（本工程实现，未被替换）

- **EPUB 解析**：Rust 原生结构解析（container/OPF/nav/NCX）+ Jsoup 块解析，
  自动回退链（so 缺失或解析失败走 Kotlin 路径）。阅读器通过 `sourceOpener`
  注入点复用这条管线，**没有**改用上游解析器。
- **断点续读**：页进度存既有 DataStore，退出时落库、进入时定位；
  同时刷新书架「上次阅读」。
- **阅读统计**：仍是「前台 onStart→onStop 累计、单次 ≤30 分钟」的口径。
- **主题**：仍由 `AppMiuixTheme` 统一提供；阅读器界面已全量 MiuiX 化。
- **在线阅读**：wenku8 在线阅读不走新阅读器，界面与行为不变。

## 组件与合规

- 引入 XY reader 27 个 Kotlin 文件（`core` / `archive` / `reader` / `ui`），
  保留上游包名 `com.xyreader` 与 MIT 许可；`THIRD_PARTY_NOTICES.md` 已更新。
- 新增依赖 `commons-compress`（Apache-2.0）与 `junrar`（UnRAR，仅解压），
  配套 R8 保活规则。
- **移除** LightNovelReader 126 个文件及其专属依赖
  （kotlin-result、dom4j、navigation3-runtime）。
- 新增内置字体霞鹜文楷 Lite、朱雀仿宋（SIL OFL 1.1）；MiSans 复用既有字体文件。

## 需要注意

- **阅读器设置项位置变了**（改为 XY reader 的布局），原有能力都还在。
- **进度口径变了**：新版按「页」记进度（分页依赖字号与边距，无法与旧的「章 + 段」
  稳定换算）。旧进度不再用于本地 EPUB 续读，书架「上次阅读」仍照常更新。
- **APK 体积增大约 23MB**（两款内置 CJK 字体）。

## 验证重点

1. 打开 EPUB：正文按页排版，左右翻页与上下滚动都能正常翻
2. 目录抽屉：可翻卷、当前章高亮、点击跳转；书签可增删
3. 阅读设置：字号 / 行距 / 边距 / 背景调整后**重新分页且保留当前阅读位置**
4. 续读：读到中间退出 → 重开回到原页；书架「上次阅读」时间更新
5. 亮度 / 屏幕方向 / 常亮 / 手势锁生效
6. 回归：wenku8 在线阅读、导出（缓存 / 富文本 / 卷级目录）不受影响
