# 文库 EPUB 工坊 v0.19.0-alpha05（预发布）

> 版本：v0.19.0-alpha05（versionCode 30） · 类型：**预发布 prerelease**
> 基线：v0.19.0-alpha04

这一版把 alpha04 之后累积的 20+ 个提交收拢成一次发布，重点统一了「页名」和「返回」
这两件每个页面都要回答、却一直各写一遍的事。

## 本版重点：页面外框统一

### 同一屏不再有两个标题

书架、阅读、探索、设置四个一级页，以及搜索页和九个设置二级页，过去都在顶栏下方
**又画了一遍同名大标题**。顶栏本身 52dp 高、已经写着同一个页名，于是同一屏出现
`顶栏「书架」` + `内容区「书架」` 两个标题，滚动时还白占一行可用高度。

现在页名只有一个来源：`PageChrome.chromeTitle()`。页内只保留副标题、说明文字与操作位
（书架页的说明、探索页的来源行与搜索入口、阅读首页的书签入口、设置索引页的「分类」抽屉入口）。

### 返回键不再退出 App

这是本版修的**实质缺陷**。探索详情、搜索、书签中心、导出记录、导出向导这五个全屏页
过去**没有**接系统返回键（只有设置二级页接了）：按一下返回，应用直接退出。而这些页面
底部导航是隐藏的，用户没有别的退路。

现在：

- 全屏页按返回 → 关掉当前这一层，回到下面那层；
- 设置二级页按返回 → 回到设置索引页；
- 导出向导的**打包页**按返回 → 退回选章节（**已选的章节不会丢**），其余步骤才关闭向导；
- 主导航上按返回 → 不拦截，正常退出。

顶栏左侧同时多了一个返回图标按钮，与系统返回键指向同一个动作。它取代了原先各页自己画的
文字按钮（`‹ 返回探索`、`‹ 返回`、`‹ 关闭向导`、`‹ 返回设置`），位置与措辞从此统一。

### 顺带的一致性

- 底部导航的显隐判据与页面层级共用同一个函数，不再各写一份条件；
- 探索展开页（榜单全屏页）只留「刷新」，榜单名与返回交给顶栏。

## 收纳 alpha04 之后的功能

### 阅读

- **整书章节搜索**（在线书）：按正文关键词搜索并定位到章节。
- **书签中心**：独立全屏页，按书分组聚合两个阅读器的书签，条目带正文摘录，
  支持单条删除与整本清空。
- **上下滚动不再页间断开**：过去每页都出整屏高位图，页容量取整剩下的死区堆在页底
  （默认边距下相邻页之间空出约 305px），滚动时是明显的横向断开带。新增
  `NovelStyle.seamlessFlow`：上边距只落首页顶部、下边距只落末页底部，位图取该页实际占用高度。
- **中文正文不再有多余空格**：行内标签边界与序列化缩进会在汉字之间留空格。新增只作用于
  「两侧都是 CJK」的间隙清理，英文词间间距不受影响，并可在设置里关闭。

### 界面

- 底部导航四项：阅读 / 书架 / 探索 / 设置（对齐 LNR `MainDestination`），**「阅读」为默认首屏**。
  导出入口仍留在书架卡片菜单与探索详情里，不占一级导航。
- 书架卡片、设置分组卡、探索横排书卡、探索展开页网格全部对齐 LNR 字面规格。
- 书籍操作菜单从 `Popup` 改为轻量 Sheet；切 tab 不再丢滚动位置；左右页面边距只由宿主给一次。

### 网络

- **插图整批消失的根因**：站点 2026 年把插图迁到新图床 `pic.777743.xyz`，而白名单只放行
  wenku8 三域，请求直接失败。新增图片专用白名单，只对图片请求放行；页面、接口与会话链路
  仍严格三域。
- **入口轮换不再改写图片域**：过去会把 `img.wenku8.com/image/…` 换成主站，实测 404。
- **相对图片路径**统一钉回图片 CDN，明文 http 升 https。
- 设置 → 网络新增「直连入口」三项选择（`.net` / `.cc` / `.com`），决定第一次请求打哪个镜像；
  规范 URL、书架与 EPUB 内链永远是 `www.wenku8.net`。

### 配置

- 导入的枚举匹配改为大小写不敏感（`RecentRead` 这类驼峰枚举过去被判「取值无效」而跳过）。
- 导出键 `bookshelfSort` → `sort`，避开「导出文件不得包含书架内容」的禁词。

## 内部

- 新增 `ui/PageChrome.kt`：`shellPage()` / `chromeTitle()` / `upTarget()` 三个纯函数，
  顶栏标题、返回按钮、系统返回键、底部导航显隐全部从这里读。
- 新增 `PageChromeTest`（11 个用例）：层级优先级、标题与层级不许各说各话、
  主导航必须不拦截返回、导出向导的逐级后退。
- `DesignTokenTest` 新增两条守卫：`pageTitlesAreOnlyRenderedByTheTopBar`、
  `settingsSubPagesHaveNoInlineBackButton`。
- CI：Gradle 9.6.0 → 9.8.1、Kotlin 2.4.20 → 2.4.21。
  `dtolnay/rust-toolchain` **保持 `@stable`**——它的 ref 就是工具链通道，`v1` 会被解析成
  「Rust 1.x」，实测直接报 `'toolchain' is a required input`（第一次推 ci-latest 正是这样红的）。
- **固定下载入口**：main 上通过全部检查的构建覆盖固定标签 `ci-latest`，
  下载地址永不过期，不必再进 Actions 解压 artifact。

## 升级说明

无数据迁移。配置 schema 仍为 v2，旧 v1 文件可正常导入。

## 已知限制

- 预发布版，排版细节仍在调整。
- 「中文之间不留空格」只作用于两侧都是 CJK 的情况；若你的正文确实需要在汉字之间保留空格，
  可在设置 → 阅读器设置里关闭。
- 书签中心的在线书书签只能按「该书的续读进度」打开，不承诺跳到书签当时的具体页——
  页轴与起始章绑定（AGENTS §4.8），离线时无法重建同一个页轴。
