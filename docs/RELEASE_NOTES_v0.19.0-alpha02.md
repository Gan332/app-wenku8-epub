# 文库 EPUB 工坊 v0.19.0-alpha02（预发布）

> 版本：v0.19.0-alpha02（versionCode 27） · 类型：**预发布 prerelease**
> 基线：v0.19.0-alpha01

这一版在 alpha01 的基础上补三项阅读侧改进，并清掉整套已经没人调用的旧阅读渲染层
（净删约 1,090 行）。**无数据迁移、无配置变更**，从 alpha01 直接覆盖安装即可。

## 这一版做了什么

### 阅读器页内搜索

底部工具栏新增搜索入口（与「复制文字」同一条件：仅文字小说）：

- 输入关键词后**全书扫描**，结果按页码列出「第 N 页 + 上下文摘要」；
- 命中段在摘要里用 `‖` 分隔并高亮，点结果直接跳到该页；
- 扫描**逐页释放 `renderMutex`**，不会长时间占着翻页渲染锁；
- 面板显式显示「已扫 x / y 页」进度，长书也能看出还在动。

在线阅读只搜**已加载**的章节（没抓下来的正文尚不存在），这是预期行为。

### 热力图改为动态范围

按你**最早一次非零阅读记录**铺开到今天，上界 52 周；没有记录时退化为 1 周。
原先固定 26 周，长期使用的人看不到更早的记录。

### 书架分组头箭头

收起时旋 180°，时长经 `Motion.duration()` 换算并尊重系统「移除动画」。
alpha01 的已知问题里提到「MiuiX 图标集没有可旋转的展开箭头」，这版补了一个
`expand_more_24px` 解决。

## 内部：移除旧阅读渲染层

`reader/` 下这几个文件**已无任何调用点**，本版整体删除：

| 文件 | 行数 | 说明 |
| --- | --- | --- |
| `ReaderScreen.kt` | 795 | 旧渲染层 `ReaderScreenCore`（0.13.0 起本地阅读走 xy-reader，0.14.0 起在线阅读也改走 xy-reader） |
| `FlatBlocks.kt` | 75 | 旧「摊平列表」滚动实现 |
| `RemoteImage.kt` | 55 | 旧正文插图加载 |
| `ReaderImage.kt` | 21 | 旧插图状态类型 |
| `ReaderActions.kt` | 102 | 旧渲染层回调接口（文件更名并裁剪为 `ReaderUiState.kt`） |

**阅读行为不变**：本地与在线两条链路都走 `com/xyreader`，与本次删除无关。
`ReaderUiState` 与 `controlsShown` / `resolveBack` / `withPanel` 三个纯函数**保留**——
它们由 `CoreSmokeTest` 直接测试，是阅读交互的回归基线，现落在 `reader/ReaderUiState.kt`。
只测已删符号的 6 个失效用例（摊平映射、段落下标、文字对比度纠偏）一并移除。

Android），密度是否合适需要你真机看一眼。如果某个页面还挤、或者哪里过松了，
