# 文库 EPUB 工坊 v0.15.0 发布说明

> 版本：v0.15.0（versionCode 22）
> 基线：v0.14.0

## 一句话

**站内搜索能翻页了**：结果不止第一页，底部「加载更多」按页追加，跨页自动去重。

## 变更详情

### 1. 搜索翻页

- `modules/article/search.php` 请求带 `page=` 参数（页码从 **1** 开始）
- 搜索结果列表底部新增「加载更多」按钮，加载中禁用并显示进度
- 跨页结果按书籍 `id` 去重后追加，不覆盖已展示的条目
- 翻到末页后按钮消失，改为「已加载第 N 页」

### 2. 分页状态解析更稳

- **页码以请求参数为准**（`page=` 才是服务端的真相）
- `em#pagestats` 只用来推断**总页数**，认两种文案：`2/5`、`2 / 5`、`共5页`
- 拿不到总页数时退回「下一页」锚点判断；两条路都拿不到才算末页
- 不再把分页文案里的第一个数字当作当前页——文案格式一变就会跳页

### 3. 并发响应防倒挂

搜索请求带单调序号：中途改关键词、切换「书名/作者」、或连点「加载更多」时，
较早的响应直接丢弃，不会把旧结果盖到新结果上。

### 4. 节流档位对齐

搜索改走**交互档**节流（`fetchTextInteractive`），与探索详情、官方标签同一口径。
白名单、内网地址拦截、429 `Retry-After` 退避、重定向复校验**完全不变**
（交互档只是允许突刺：6 秒滑动窗口内最多 6 次，超限自动退回 1 秒/请求）。

### 5. 内部重构（对用户无感）

抽出 `SessionGate`（`hasSession` / `clear`）会话门接口，`Wenku8SessionStore` 实现它；
搜索提供者、探索数据源、wenku8 书源改为依赖接口而非具体实现，单测可注入假实现，
不必在 JVM 单测里碰 Context / Keystore。

## 合规边界（无变化）

- `search.php` 是登录墙内接口，**只在你本人登录后**用你的会话 Cookie 访问
- 返回登录页即清会话并提示重新登录，**不做任何匿名规避**，不内置任何第三方凭据
- 免登录书目索引（`articleinfo.php`、章节目录、年度/月度榜单）仍走独立的无 Cookie 客户端

## 已知限制

- 未登录时搜索按钮会提示先登录（与 0.14.x 一致）
- 分页总数取决于源站 `em#pagestats` 文案；若源站改版且既无总页数也无「下一页」锚点，
  会在第一页就显示为末页——清空搜索历史后重新搜索即可恢复

## 升级说明

无数据迁移，无配置变更，直接覆盖安装即可。
