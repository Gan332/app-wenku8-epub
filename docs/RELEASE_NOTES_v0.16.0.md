# 文库 EPUB 工坊 v0.16.0 发布说明

> 版本：v0.16.0（versionCode 23）
> 基线：v0.15.0

## 一句话

直连被 Cloudflare 403 拦住时，可以把**免登录公开页**改走第三方中继，开关与端点都在设置里。

## 使用方法

1. 打开「设置 → 概览」底部的 **第三方中继（仅公开页）**
2. 在「中继端点」填入形如 `https://relay.example.com` 的地址，点「保存端点」
3. 打开上方开关

端点必须由你自己填写——**应用不内置任何中继地址**。原因见下方「为什么没有内置地址」。

## 哪些请求会走中继

| 链路 | 端点 | 是否走中继 |
| --- | --- | --- |
| 免登录公开页 | `articleinfo.php`、目录页 `/novel/{分类}/{id}/index.htm`、`/zt/sugoi/`、`/zt/booklist/`、`authorarticle.php`、封面图 | **可走**（随开关） |
| 登录墙内接口 | `search.php`、`toplist.php`、`tags.php`、`login.php` | 始终直连 |
| 来源地址 | `book/{id}.htm`（书架与 EPUB 内链） | 始终直连 |

## 安全与合规边界

- **中继收不到你的登录 Cookie**：只有 wenku8 自身域名允许携带 `jieqiUserInfo` / `PHPSESSID`，
  由 `Wenku8Url.carriesSession` 按 host 把关，Cookie 存取两侧同时过滤
- **书架与 EPUB 里不会留下第三方地址**：解析出口会把中继 URL 还原成 wenku8 原域；
  只有真正下载图片的那一刻才改写到中继，缓存键仍是 wenku8 地址
- **端点校验**：只接受 `https://域名[:端口]`；拒绝 http、IP 字面量（含内网地址）、
  明文凭据、以及 wenku8 自身域名
- **限流与退避不变**：仍遵守全局 1 秒/请求与 HTTP 429 的 `Retry-After` 退避
- 中继只是**换传输路径**，不新增任何接口，也不绕过源站的登录控制

## 为什么没有内置地址

MewX 官方 App 曾提供同类「第三方中继」开关并公示政策，但**中继地址从未公开**：

- 1.x 源码里相关常量已被移除（`Wenku8API.BASE_URL = UNKNOWN`）
- `wenku8.mewx.org` 是其前端页（Cloudflare Pages SPA），不是反向代理
- 项目文档只提到「API 位于 Cloudflare Worker 中继之后」，没有给出端点

因此应用默认关闭且不填任何猜测地址。你若持有可用端点，自行填入即可。

## 已知限制

- 中继由第三方运营，其数据新鲜度、完整性与可用性均不受本项目控制
- 中继若不可用，请关闭开关回到直连；关闭时行为与 v0.15.0 完全一致
- 中继只影响公开页；若源站登录墙内接口也被网络阻断，仍需直连才能用搜索
