# 文库 EPUB 工坊 v0.9.1

修复 0.9.0 中阅读器菜单栏呼不出、按钮不可点的问题。

## 修复

### 点正文呼不出菜单栏（0.9.0 引入）

0.9.0 把点按切换改成只翻转 `controlsVisible`，但顶栏/底栏的显隐仍然只看
`isImmersive` —— 一个只写不读的状态。默认沉浸模式下点正文没有任何反应，
目录、设置、上一章/下一章按钮全都无法到达。

现在判据改为 `controlsVisible || 面板打开`：点正文呼出菜单栏，再点收起。

### 菜单栏按钮被状态栏压住

edge-to-edge 下，系统栏可见时 MiuiX 顶栏没有状态栏 padding、底栏没有导航栏
padding，按钮落在系统栏的触摸区里点不到。现在顶/底栏按系统栏 inset 自适应
让位；系统栏隐藏（沉浸态）时 inset 为 0，布局不变。

### 在线阅读与 EPUB 行为不一致

在线阅读的点按仍在翻转 `isImmersive` 并连带切换系统栏。已与 EPUB 侧对齐，
只切换控件显隐。

### 返回键

决策抽成纯函数 `resolveBack()` 并补单元测试：面板优先关闭 → 菜单栏可见则退出
→ 隐藏则先呼出（与 0.8.x 一致），不再修改沉浸设置，也没有循环。

## 升级说明

- 无数据迁移变更（沿用 0.9.0 的包名 `com.example.hyperreader`）。
- release 包经 R8 压缩，签名由 CI Secrets 提供。

## 验证重点

1. 默认沉浸设置下：点正文 → 菜单栏滑出；再点 → 收起。
2. 顶栏（返回/目录/设置）与底栏（上一章/下章/目录/设置）全部可点。
3. 打开目录或设置面板，返回先关面板；沉浸态下返回第一下呼出菜单、第二下退出。
4. 关闭沉浸模式后，顶/底栏不被状态栏/导航栏遮挡。
5. 书架在线阅读与 EPUB 阅读行为一致。
