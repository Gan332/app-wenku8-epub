# 文库 EPUB 工坊 v0.9.5

导出 EPUB 模块重写：速度、可视化、排版还原、插图与卷级目录跳转。

## 排版还原

### 正文保留网页强调格式

旧版把章节转成纯文本（`root.text()`），粗体/斜体全部丢失。现在：

- **内联强调保留**：粗体、斜体、下划线、上下标原样进 EPUB；
  `style` 中的 `font-weight:bold`、`font-style:italic`、`text-decoration:underline`
  会规范化成对应标签。
- **安全**：强调标签白名单由代码生成（`b/strong/i/em/u/s/sup/sub`），
  输出结构上不存在属性注入面；`<script>`、`javascript:`、`onclick` 必然被剥除
  （有专门的 XSS 回归测试）。
- 普通段落仍是纯文本，不无谓引入 HTML。
- **在线阅读零变化**：`preserveInlineFormat` 默认关闭，仅导出链路开启。

### 卷级目录跳转

多卷书的 nav.xhtml 按**卷分组嵌套**（卷名不产生链接），EPUB3 阅读器目录里
先卷后章；链接数恒为「书籍信息 + 章数」，应用内阅读器回读不受影响。
插图（`figure` 原位）与章间跳转沿用既有实现。

## 速度

- **导出缓存**（URL 内容寻址）：正文页与插图命中即 0 请求 ——
  **第二次导出同一本书接近秒级完成**，不再受 1s/请求的源站限流拖累。
  上限 512MB，按新旧自动淘汰；失败任务保留缓存以便重试。
- **跨章 URL 去重**：同 URL 插图只下载一次。
- **进度节流 250ms**：内存状态每次即时更新；DataStore 落盘与通知 IPC
  最多每 250ms 一次（旧实现每张插图各落盘一次）。
- 首次导出的请求数受源站 1s/请求保护约束 —— 只减少请求数，不挑战限流。

## 可视化

进度卡片与导出详情页新增：

- **阶段徽标**：抓取章节 / 下载插图 / 下载封面 / 打包 EPUB
- **预计剩余**：`剩余约 2 分钟`（按限流节奏估算，标注「约」）
- **插图 n/总数**（总数随抓取逐步精确）
- **缓存命中 N 项（0 请求）** —— 缓存提速直接可见
- 通知栏同步显示阶段与 ETA

## 升级说明

- 无数据迁移变更（沿用 `com.example.hyperreader`）。
- `JobProgress` 新增三个字段带默认值，历史任务数据兼容。

## 验证重点

1. 导出一本**带粗体/斜体、分卷、带插图**的书 → 外部阅读器打开：
   强调格式在、插图在原位、目录按卷分组可跳、点章直达。
2. **同一本书导第二次**：进度显示「缓存命中 N 项」，导出时间从分钟级降到秒级。
3. 进度卡片显示阶段、剩余时间、插图 n/总、缓存命中。
4. 在线阅读回归：正文与图片行为与 0.9.4 一致。
5. 应用内阅读器打开新导出的 EPUB：目录跳转、插图三态正常。
