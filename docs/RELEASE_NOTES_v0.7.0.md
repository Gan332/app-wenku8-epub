# v0.7.0 发布说明

发布日期：2026-09-25

## 书籍详情

- 新增封面大图（3:4 竖版），点击进入全屏预览
- 全屏预览支持双指缩放（1x–5x）、拖动与双击还原
- 字数、最后更新、状态、章节数、来源改为独立元数据控件，每行一个卡片
- 字数使用千分位显示（`207,559 字`）
- 全部元素交由外层滚动容器承载，长简介不再被裁切
- 标签改为可点击胶囊，跳转到本地搜索
- 已在书架时按钮显示「已在书架」并禁用

## 书架

- 卡片显示封面缩略图与书名
- 点击卡片进入书籍操作二级界面，不再在卡片上平铺按钮
- 二级界面支持：继续阅读、打开详情、置顶、展开同作者作品、从书架移除
- 移除需二次确认，且不删除本地 EPUB 文件

## 设置

设置总览只列分类入口，各分类独立成页：

| 入口 | 内容 |
| --- | --- |
| 主题与外观 | 配色模式、动态色、预设强调色、取色器 |
| 阅读器设置 | 背景、背景色、文字色、字号、字重、行高、段距、边距、翻页、常亮、沉浸、字体 |
| 阅读统计 | 总时长、今日、连续天数、近 7 天、每本书排行 |
| 书目缓存 | 缓存本数、更新时间、更新与清空 |
| 关于 | 版本、边界、参考项目 |

- 阅读统计从底部导航移入此处
- 底部导航由 5 项减为 4 项：书架、探索、创建、设置

## 被动触发

除用户点击外，应用不发起任何书目网络请求：

- 「更新书目缓存」仅存在于设置 → 书目缓存
- 探索页只显示缓存状态，缓存为空时提供跳转入口
- 打开未缓存书籍时由用户点击「加载完整详情」后才请求
- 书架与探索列表只读本地索引

## 封面加载

- 自研封面加载，复用既有 `Wenku8HttpClient` 的 1 秒限流与 429 退避
- 内存 LruCache + 磁盘缓存（`cacheDir/covers`）
- 按目标宽度下采样，避免小卡片加载大图
- 未引入 Coil/Glide，避免第三方库绕过限流

## 已知限制

- 封面首屏需要一次网络请求，之后走缓存
- 缩放手势为自行实现，未引入 panpf 等重依赖
