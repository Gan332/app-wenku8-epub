# 文库 EPUB 工坊 v0.19.0-alpha01（预发布）

> 版本：v0.19.0-alpha01（versionCode 26） · 类型：**预发布 prerelease**
> 基线：v0.18.0-alpha01

这一版把三处主界面按 [LightNovelReader](https://github.com/dmzz-yyhyy/LightNovelReader)
（Apache-2.0）的做法重排了一遍，并顺手放宽了全局间距。功能面是净增量，
**无数据迁移、无配置变更**，从 v0.18.0-alpha01 升级可直接覆盖安装。

建议把它当「尝鲜版」：三处重构刚落地，**密度与手感仍待真机确认**。

## 这一版做了什么

### 阅读统计换成热力图

原来的「最近 7 天」进度条变成 GitHub 式年度网格：**列 = 周、行 = 周内七天**，五档色阶。

- 色阶阈值不写死分钟数，而是按你**非零阅读时长的 25% / 50% / 75% 分位**动态计算，图例标注最高档——
  轻度读者和重度读者都能得到分布均匀的五档，不会出现「一片全白」或「一片全黑」。
- 点选某一天显示当天时长；网格可横向滚动，进来时停在最近一周。
- 颜色跟随应用主题，亮/暗色都合适。

### 书架分组折叠

书架切成可折叠的**「置顶 / 全部」**两段，分组头吸顶（滚动时钉在顶部），带组图标和展开箭头。

- 卡片封面放大到 LNR 的 94×144，作者名改用强调色。
- **点卡片即读、更多菜单等交互完全不变**（AGENTS §4.6.1）。

> 说明：LNR 书架第一段是「更新中」（有新章节未读），需要额外追踪最新章节数据。
> 本版**没有**引入这个字段，只用既有的「置顶」分组——不为视觉差异引入无用数据。

### 探索页

- 12 个榜单的切换从横向 Chip 行换成**可滚动 TabRow**，不再挤在一起难点。
- 新增**下拉刷新**。
- 切换榜单时列表自动回到顶部。

### 全局排版放宽

如果你之前觉得部分控件挤，这次一并调了：

- 间距六档整体上调一档（4/8/12 → 6/10/14dp，大间距 16/24 → 18/26dp）。
- 卡片内边距 14 → 16dp，紧凑行高 44 → 48dp（与最小触控区对齐）。
- 顺手**清理了 37 处绕过令牌直接写 `dp` 的间距**，消除「部分控件拥挤、部分宽松」的不一致。

阅读器界面（xy-reader）按项目约定保持上游原样，未受本次调整影响。

## 已知问题

- **预发布版**：三处重构刚落地，界面密度与你的设备有关，仍可能需要微调
- 书架分组头用两个图标切换（展开/收起），没有旋转动画——MiuiX 图标集里没有可旋转的展开箭头
- 热力图默认展示近 26 周（约半年），再往前的历史暂不支持
- 自建中继需要你有一个 Cloudflare 账号（免费额度即可）

## 升级说明

无数据迁移、无配置变更。默认行为与 v0.18.0-alpha01 一致（中继开关默认关闭）。
从 v0.18.0-alpha01 直接覆盖安装即可。

## 反馈

三个界面我都**没法在本地跑起来看效果**（项目约定不在本地编译 Android），
所以密度是否合适需要你真机看一眼。如果某个页面还挤、或者哪里过松了，
告诉我具体页面，我定向调整——现在间距只有一个来源（`UiDimens`），改一处即可全局生效。
