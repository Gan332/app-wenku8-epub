# 文库 EPUB 工坊 v0.12.0

阅读器换成 **LightNovelReader 的内置阅读器**（Apache-2.0），数据层仍是本工程实现。

## 换了什么

- **按页排版翻页引擎**（LNR 的 `FlipPageContentComponent`）：真正的分页排版，
  按屏幕高度切分段落并分页，而不是简单滚动。
- 章节选择面板（分卷展开、当前章高亮、自动定位到当前章）。
- 图片查看器（长按/双指轻点全屏、缩放平移）。
- 阅读器设置面板（字号/字重/行高/段距/边距/背景/翻页方式/常亮/沉浸模式）。
- 顶栏电量与时间指示、翻页动画选项。

## 保留了什么（本工程实现，未被替换）

- **EPUB 解析**：Rust 原生结构解析（container/OPF/nav/NCX）+ Jsoup 块解析，
  自动回退链（so 缺失或解析失败走 Kotlin 路径）。
- **断点续读**：进入时从既有 DataStore 断点换算成 LNR 章节定位；
  退出时把章内阅读比例换算回段落序号写回，并更新书架「上次阅读」。
- **图片管线**：`CoverRepository`（内存 LruCache + 磁盘 + 按宽度降采样 +
  走全局限流客户端），EPUB 内插图解包落 `cacheDir/lnr-images`。
  **没有引入 Coil/panpf**（图片字节不得绕过限流，这是 AGENTS 的硬约束）。
- **阅读统计**：仍是「前台 onStart→onStop 累计、单次 ≤30 分钟」的口径。
- **主题**：仍由 `AppMiuixTheme` 统一提供，阅读器通过 `LnrAppTheme` 投影取色。

## 组件与合规

- 引入 LNR **126 个 Kotlin 文件**（`:api` 阅读器子集 + reader UI），保留原包名与
  Apache-2.0 文件头；仓库根新增 `THIRD_PARTY_NOTICES.md` 完整声明。
- 引入的代码做了 MiuiX 化（material3 全清）、去 Hilt、去 Coil/panpf/Room。
- **GPLv3 文件未引入**（`RollingNumber`，来自 EhViewer）。
- 裁掉了主设置页专属的更新渠道/排序选项组（零引用且依赖 Hilt）。

## 需要注意

- **阅读器设置项位置变了**（改为 LNR 布局），原有设置能力都还在，但位置不同。
- **阅读器样式二级页**未接入（点「阅读器样式」会退出阅读器）—— 本工程没有该页面。
- 旧的自研阅读器壳 `ReaderActivity` **暂留**在代码里作对照（R8/首帧/手势这类问题
  只能在真机暴露）；确认新壳稳定后下个版本删除。

## 升级说明

无数据迁移变更（沿用 `com.example.hyperreader`），书架与阅读进度继续可用。

## 验证重点

1. 打开 EPUB：正文排版正确，翻页模式下**按页排版**而非整段滚动
2. 章节选择面板：可翻卷、当前章高亮、点击跳转
3. 长按图片 → 全屏查看，可缩放平移；坏图显示「图片无法显示」占位并可重试
4. 设置面板：字号/行高/背景等调整实时生效
5. **断点**：读到中间退出 → 重开回到原章；书架「上次阅读」时间更新
6. 回归：wenku8 在线阅读、导出（缓存/富文本/卷级目录）不受影响
