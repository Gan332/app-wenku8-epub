# 文库 EPUB 工坊 v0.17.0 发布说明

> 版本：v0.17.0（versionCode 24）
> 基线：v0.16.0

## 一句话

这次是**信息架构重构**：应用以**阅读器为核心**，导出退回到它该在的位置——书籍菜单里的次级动作。

## 改了什么

### 底部导航只剩三项

| 之前 | 现在 |
| --- | --- |
| 书架 / 探索 / **创建** / 设置 | 书架 / 探索 / 设置 |

「创建」tab 原本是 5 步导出向导（源站→详情→章节→导出→进度），现已移除。

### 书架点书即读

- **本地 EPUB** → 直接进 xy-reader
- **远程书（未导出）** → 直接进在线阅读器，自动跳到上次读到的章节，并记录阅读时间
- 详情与导出不再挡在阅读前面，改到卡片右上角的「更多」菜单：
  - **查看详情**：打开书籍详情（简介、标签、字数、同作者）
  - **导出 EPUB**：进入导出向导
  - **开始阅读**：显式再发起一次在线阅读（本地书则是「打开阅读」）

### 导出向导（四步，二级页）

1. **解析目录** —— 显示加载进度；失败时显示原因并可原地重试
2. **选择章节** —— 搜索、全选/清空、默认全选
3. **打包设置** —— 是否含封面、章节数、格式说明
4. **进度** —— 实时进度、取消、警告清单；完成后可保存或分享

### 导出记录独立成页

原先折叠在书架页顶部，现在从「设置 → 概览 → 导出记录」进入；通知栏点历史任务同样进这一页。书架页只保留「进行中的导出」概览。

### 探索详情页保持原样

「在线阅读」仍是主按钮，两个「导出 · 引擎」小按钮仍可一键导出指定引擎（不受全局引擎设置影响）。

## 不再支持

- **粘贴网址 / 输入书籍 ID 直接创建导出**：以前在「创建」tab 第一步，现在导出必须从具体书籍发起。书架里没有的书，先在探索页找到它（可直接在线读或加入书架），再从菜单导出。

## 升级说明

无数据迁移，无配置变更。已有的书架、本地 EPUB、导出任务与进度全部保留；正在进行的导出任务进度条照常显示在书架页。

## 已知限制

- 导出向导从书架发起后，中途关闭会放弃当前章节选择（下次需重新勾选）
- 远程书首次阅读仍需等待目录预取（受源站限流影响，1 秒/请求）
