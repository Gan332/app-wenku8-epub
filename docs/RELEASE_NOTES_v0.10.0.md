# 文库 EPUB 工坊 v0.10.0

MiuiX 动效与组件全面化；EPUB 解析引入 Rust 核心（可回退）。

## MiuiX 动效与组件

### 动效

- **切页转场**：书架 / 探索 / 创建 / 设置 之间、以及创建流程步骤之间，
  横向滑入 + 淡入（MiuiX `DecelerateEasing` 缓动）——原来是硬切。
- **列表项动画**：书架、导出记录、搜索结果、探索列表、目录条目在增删/重排时平滑过渡。
- **阅读器**：
  - 控件栏收展改用 **MiuiX folme 弹簧**（更有弹性）
  - 插图加载完成**淡入**出现（不改变尺寸，排版不跳）
  - 翻页模式 ↔ 上下滚动切换淡入淡出过渡
  - 目录跳转**动画滚动**（打开书的断点恢复仍是瞬时精准落位）
  - 设置面板数值（字号/字重/行距…）拖动时数字淡变

### 组件

- 搜索页接入 MiuiX **SearchBar**（历史词为展开内容）
- 根消息改用 **Snackbar**（可滑走、自动消失）
- **书架交互重做**：点卡片直接打开书；行尾「更多」按钮弹操作菜单
 （在线阅读 / 同作者作品 / 置顶 / 移出书架），删除旧的全屏操作弹窗
- 按压遮罩与回弹经核验已由 `MiuixTheme` 全局注入（0.9.3 起生效）

### 如实说明两处降级

- **未加下拉刷新**：书架与探索都是本地实时数据，没有真实刷新动作，
  做假转圈没有意义
- 章节选择页的过滤框保持原样（它是列表内过滤，不是搜索栏）

## Rust EPUB 解析核心

- 新增 `rust/epub-core`：**手写** EPUB 结构解析（container/OPF/nav/NCX →
  章节列表 + HTML），参考成熟项目 plato（1705★）的语义、不 vendor 其代码
 （候选 `epub` crate 的仓库已 404，自写避免上游消失风险）。
- **职责边界**：Rust 只解析结构；段落/图片块的生成仍由 Kotlin Jsoup 完成，
  现有全部解析测试原样有效。
- **安全回退链**：so 缺失 / 结构解析失败 / 超限 → **自动回退**原有
  zip+Jsoup 路径。native 是加速路径，不是单点依赖 —— 第三方 EPUB
 （如 GBK 文件名等边缘情况）最坏也只是走旧路径，不会崩。
- 解压限额与旧实现一致（单条 30MB / 累计 200MB）。
- CI 新增 Rust 工具链与 cargo 缓存；`cargo test` 5 个结构解析测试进流水线。
- 三 ABI（arm64-v8a / armeabi-v7a / x86_64）so 构建期生成，不入库。

## 修复

### 导出的 EPUB 在阅读器里图片不显示（0.9.x 遗留）

阅读器解析插图路径时把 packageDir 拼了两次，产出 `EPUB/EPUB/images/…`，
zip 里查不到该条目 —— 表现为图片全部不显示（外部阅读器正常，
因为 EPUB 文件里写的相对路径本身是对的）。native 与旧路径共用同一函数，
一处修复同时覆盖两条链路。**装上这版后，之前导出的书图片应该直接出现。**
