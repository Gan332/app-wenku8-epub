# v0.1.0 发布说明

发布日期：2026-09-25

## 新增

- 本机单用户中文 Web 应用，固定默认监听 `127.0.0.1:3210`。
- 公开 wenku8 书籍页、目录页、正文章节和插图页解析。
- GBK/GB2312 解码、正文清理、插图 URL 解析和图片本地化。
- EPUB 3 打包，包含元数据、导航、NCX、标题页、章节、CSS、封面和图片。
- 串行后台任务、进度、取消、跳过警告、历史记录和中文文件名下载。
- 离线回归测试、真实公开源站验收、EPUB 结构检查和发布包校验。

## 安全与边界

- 仅接受 wenku8.net、wenku8.cc 和 wenku8.com 的书籍/目录 URL。
- 阻止本机和内网地址，重定向后重新执行地址安全检查。
- 不支持登录、付费墙、Cloudflare 验证或验证码绕过。
- 不保存账号 Cookie、密码或 Token。

## 已知限制

- 依赖源站公开 HTML 结构；源站改版时解析器可能需要更新。
- 真实源站可能限流或临时不可用，此时 `npm run test:live` 会失败。
- 不提供公网访问、多用户、数据库、云同步或自动内容更新。
- 端用户发布包不携带源站网页测试样本；样本仅用于仓库内离线回归。
- EPUB 主要以 EPUB 3 为目标，同时保留 NCX 兼容目录。

## 回滚

1. 停止本机服务。
2. 备份 `data/jobs/` 和 `output/`。
3. 切换到上一个稳定标签或提交。
4. 重新执行：
   ```powershell
   npm ci
   npm run verify
   ```
5. 如源代码回滚但本机数据仍需保留，不要删除 `data/jobs/` 和 `output/`。
