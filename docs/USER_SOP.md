# 用户操作 SOP（Wenku8 EPUB 工坊 v0.1.0）

## 1. 适用范围

本 SOP 适用于本机单用户模式。服务默认只监听 `127.0.0.1:3210`，不对局域网或公网开放。

仅处理无需登录、付费或访问验证即可读取的公开页面。请确认你对下载内容拥有合法使用权，并遵守源站条款。

## 2. 启动

### 方式 A：Windows 一键启动

1. 打开项目目录。
2. 双击 `start.bat`。
3. 首次运行等待依赖安装完成。
4. 浏览器会自动打开 `http://127.0.0.1:3210`。
5. 保持命令窗口打开；结束时按 `Ctrl+C`。

### 方式 B：命令行

```powershell
npm install
npm start
```

如果浏览器没有自动打开，手动访问 `http://127.0.0.1:3210`。

## 3. 创建 EPUB

1. 在“添加书籍”步骤输入以下任一种内容：
   - 书籍页：`https://www.wenku8.net/book/2835.htm`
   - 目录页：`https://www.wenku8.net/novel/2/2835/index.htm`
   - 书籍 ID：`2835`
2. 点击“解析书籍”。
3. 核对书名、作者、分类和章节数量。
4. 使用搜索框定位章节；使用“全选”“清空”调整选择。
5. 选中至少一个章节。
6. 点击“继续导出”。
7. 选择是否包含封面。
8. 点击“开始生成 EPUB”。
9. 等待进度达到 100%。
10. 阅读任务警告：
    - 单个章节或图片失败时，其余内容仍会生成。
    - 所有章节失败时，不会生成空 EPUB。
11. 点击“下载 EPUB”。
12. 用 EPUB 阅读器检查书籍信息、目录、正文、图片和封面。

## 4. 任务状态

| 状态 | 含义 | 操作 |
| --- | --- | --- |
| 等待中 | 任务已创建，尚未开始 | 等待或取消 |
| 处理中 | 正在下载正文、图片或打包 | 等待或取消 |
| 已完成 | EPUB 已生成 | 下载或查看历史记录 |
| 失败 | 任务未能生成 EPUB | 查看错误，修正后重建 |
| 已取消 | 用户主动取消 | 需要时重新创建 |

取消任务不会删除已有历史记录。关闭或重启应用时，仍在运行的任务会标记为失败。

## 5. 文件与隐私

- 任务记录：`data/jobs/`
- EPUB 输出：`output/`
- 应用不会自动清理这些文件。
- 确认不再需要后，手动删除对应文件和任务 JSON。
- 项目不读取或保存用户账号 Cookie、密码、Token。

## 6. 故障处理

### 页面要求浏览器验证

停止操作。应用不会绕过验证。请确认页面本身可公开访问，或改用其他你有权访问、无需验证的页面。

### HTTP 403 / 429

源站拒绝或限制了请求。等待一段时间后再试；不要增加代理轮换或其他绕过措施。

### 章节失败

查看任务警告，单独重新选择失败章节生成新任务。已成功章节不会自动合并到另一个任务。

### 图片失败

图片会跳过，正文和其他图片继续生成。重新生成可再次尝试；若资源持续不可用，保留正文 EPUB。

### EPUB 无法打开

1. 运行 `npm run smoke:epub` 检查本地生成器。
2. 使用最新版 EPUB 阅读器重新打开。
3. 若仍失败，保留终端错误信息和任务警告供排查。
