# 文库 EPUB 工坊 v0.18.0-alpha01（预发布）

> 版本：v0.18.0-alpha01（versionCode 25） · 类型：**预发布 prerelease**
> 基线：v0.17.0

这是本项目转向**预发布节奏**后的第一版（标签带 `-alphaNN`）：功能面大、布局与动效仍在调整，
建议把它当「尝鲜版」，反馈问题后再转正式版。

## 这一版做了什么

### 界面尺寸体系化

新增 `ui/UiDimens.kt`：触控最小 48dp、行高 44dp、间距六档、字号七档、动效时长。
之前字号有 15 种、间距 12 种混在各处，现在全部走令牌——**改一处即可全应用统一**。

### 详情页

- **章节目录**：默认预览 20 章 → 可搜索（标题/卷名）→ 展开/收起（带动画）→ 限高滚动。
  **点某一章直接在线读这一章。**
- **字段级隔离**：状态、字数、更新、章节数、来源各一张独立卡片；标签/简介/操作各自成卡。

### 探索页（按 LNR 的结构重排）

- 顶部搜索入口 + 分区（本地书目 / 榜单 / 标签）
- 榜单是**横向滑动书卡**，行尾「更多」进**全屏榜单页**（网格 + 刷新）
- 搜索成为独立二级页

### 动画细节

交错入场、卡片按压反馈、目录展开动画、加载骨架微光（shimmer）。
全部尊重系统「移除动画」；长列表只对首屏项做延迟，靠后的书不会等几秒才出现。

### 设置页（按 Kazumi 的结构重排）

- 分类 + 分组：账号 / 阅读 / 外观 / 网络 / 数据 / 关于
- 分类侧栏：宽屏左侧常驻，窄屏抽屉
- 轻量编辑（导出引擎）改用底部弹层

### 账号与网络

- **账号分区**：登录状态、登录、退出（带确认）；应用不保存账号密码
- **顶栏账号入口**：未登录点登录，已登录进设置
- **网络分区**：中继设置 + 「测试公开端点」（匿名公开页探测）

### 自建中继（可选）

`relay/` 目录提供完整的 Cloudflare Worker 实现，用**你自己的**账号 `wrangler deploy`：

- 只代理匿名公开页，拒绝 `login/search/toplist/tags/articlelist`
- 不转发 Cookie、5 分钟缓存、每 IP 每分钟 60 次限流、不记录日志
- 部署后把域名填进「设置 → 网络」即可；不部署也不影响使用

> 不提供、也不内置任何第三方（含上游作者的）中继地址——它只是可选传输路径。

## 已知问题

- 预发布版：布局与动效仍可能微调，界面密度与你的设备有关
- 榜单展开页用「刷新」按钮而非下拉手势（MiuiX 0.9.4 无下拉刷新组件，Material 的被禁用）
- 自建中继需要你有一个 Cloudflare 账号（免费额度即可）

## 升级说明

无数据迁移、无配置变更。默认行为与 v0.17.0 一致（中继开关默认关闭）。
