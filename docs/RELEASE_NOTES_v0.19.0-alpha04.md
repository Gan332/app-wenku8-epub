# 文库 EPUB 工坊 v0.19.0-alpha04（预发布）

> 版本：v0.19.0-alpha04（versionCode 29） · 类型：**预发布 prerelease**
> 基线：v0.19.0-alpha03

这一版把 alpha03 遗留的半成品收尾，并修掉收尾过程中暴露的四个真实缺陷。

## 用户能直接感受到的修复

### 1. 中文正文里不再有多余空格

`<b>强调</b>与<i>斜体</i>` 导出后再读回会变成「强调与 斜体」——序列化缩进与行内标签边界在中文之间留下了空格。

- 行内元素改用递归拼接子节点，不再调用会规范化空白的 `Element.text()`
- 新增 CJK 间隙清理：**只**删除两侧都是中日韩字符的空格，英文单词间距不受影响

### 2. 配置导入不再误判驼峰枚举

`书架排序` 等枚举（`RecentRead`、`RecentlyAdded`…）在导入时会被判为「取值无效」而跳过——因为匹配逻辑先把取值转成大写再与枚举名精确比较，**只对全大写的枚举（`CLASSIC`/`POTATO`）碰巧有效**。现改为大小写不敏感匹配。

### 3. 配置导出不再触碰「书架内容」红线

新增的排序偏好原本用 `bookshelfSort` 作键，与「导出文件不得包含书架内容」的硬规则撞名。现改为 `sort`——**不放宽规则**，而是让键名无歧义。

### 4. 插图与同名章节

- 图片标记在解析期独立成行，potatoepub 回读不再丢图
- 目录里**标题相同但链接不同**的两个章节不再互相覆盖（成品含两个章节文件，可分别打开）

## 内部

- 补齐上一批遗漏的三个编译断点（`ConfigChange` 缺失的两个子类、`ChapterBuilder` 的构造调用、`parseBodyFragment` 的可用重载）
- `ExportPipelineTest` 新增两个端到端用例：POTATO 引擎产出真实段落且强调不转义、同名章节在成品与回读中都保留
- 设置 → 网络新增「直连入口」显示（被 Cloudflare 拦截时会自动在 `.net → .cc → .com` 之间轮换）

## 升级说明

无数据迁移。配置格式已升到 **schema v2**：新增 `shelf` 节点（导出引擎、书架排序），旧 v1 文件仍可导入；高于 v2 的文件会被明确拒绝而不是静默降级。

## 已知限制

- 预发布版，排版与导出细节仍在调整
- 「中文之间不留空格」的规则只作用于两侧都是 CJK 的情况；若你的正文确实需要在汉字之间保留空格，请告知，我们会加开关
